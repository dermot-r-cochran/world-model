# ASM and ADM

## ASM (Architectural Specification Model)

Defined in `worldspec`:
- ontology
- identity rules
- state model
- transition semantics
- evidence rules
- invariants
- worldview policy concepts

## ADM (Architectural Delivery Model)

Implemented in `worldruntime` and `worldeval`:
- persistence schema
- command/update flow
- runtime validation and enforcement
- event and violation logging
- evaluation run storage
- comparability decisions
